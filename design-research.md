# Design research (browser, 2026-10-16)

Studied before designing; patterns only, no branding, layouts or assets copied. Pinterest (login wall) and Mobbin (paywall) could not be browsed publicly, so they are not used.

| Reference | Pattern taken |
|---|---|
| [Dribbble: WDS Tabular Permission Matrix](https://dribbble.com/shots/22449475-WDS-Tabular-Permission-Matrix) | Rows = entities, columns = actors; compact cells with a clear checked/unchecked state -> paths x crawlers matrix |
| [Dribbble: Find SEO Issues. Fix What Matters](https://dribbble.com/shots/27752107-Find-SEO-Issues-Fix-What-Matters) | Severity counts whose number inherits the status colour -> the four change counters |
| [Behance: Admin Dashboard (Roles & Permissions)](https://www.behance.net/gallery/242862301/Admin-Dashboard-Roles-Permissions) | Stat row above the matrix; audit-trail detail -> inspector naming the deciding rule |
| [technicalseo.com robots.txt validator](https://technicalseo.com/tools/robots-txt/) | Editor front and centre as the empty state; mode toggles near input |
| [robotstxt.com tester](https://robotstxt.com/tester) | Placeholder-as-tutorial in the editor; edit -> target -> test hierarchy |

Resulting identity (distinct from the cron and CSP tools): pale sage paper, deep green-black ink, serif headlines for an editorial "review desk" feel, monospace rules, verdict colours always paired with symbols and words (red x newly blocked, green check newly allowed, violet rule changed).
